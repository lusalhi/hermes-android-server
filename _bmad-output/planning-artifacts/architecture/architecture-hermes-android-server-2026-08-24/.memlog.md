- (decision) AD-1: Use Native Kotlin + Jetpack Compose with MVVM/StateFlow for optimal Android system service integration and reactive UI
- (decision) AD-2: Use PRoot ARM64 Linux userland + bundled Python 3.11 runtime inside internal app storage for 100% Linux toolchain/bash skill compatibility
- (decision) AD-3: Implement ForegroundService + PARTIAL_WAKE_LOCK + BootReceiver to guarantee 24/7 uptime and survive device reboots
- (decision) AD-4: Non-blocking Coroutine I/O log streaming from subprocess stdout/stderr into circular RingBuffer (2000 lines) and Compose UI
- (decision) AD-5: EncryptedSharedPreferences for secret storage with atomic hermes.json generation prior to daemon startup
- (decision) AD-6: Optional cloudflared ARM64 sidecar process for zero-config public HTTPS webhooks and remote dashboard exposure
