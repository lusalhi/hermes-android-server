# Hermes Android Server (Hermes Node)

A standalone Android application designed to run **[Hermes Agent](https://github.com/NousResearch/hermes-agent)** locally on Android devices as an always-on AI server/gateway.

## 🎯 Project Goals
- **Zero-VPS Requirement**: Turn any Android device into an autonomous 24/7 AI agent server.
- **One-Click Experience**: Simple GUI setup (API keys, bot tokens, model choice) and a single "Start" switch.
- **Always-On Background Daemon**: Android Foreground Service with WakeLock & Doze protection.
- **Embedded Linux Userland**: Uses PRoot / Termux-based runtime to execute Python 3.11, Hermes Agent, tools, and bash skills smoothly on Android ARM64.

## ⚙️ Framework & Methodology
This project uses the **BMAD Method (Breakthrough Method of Agile AI-Driven Development)** for structured, spec-driven development.
